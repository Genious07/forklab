# ForkLab SVG identity

- `forklab-mark.svg`: primary two-policy branching mark.
- `forklab-mono.svg`: one-color version for print or restrained interfaces.
- `forklab-reverse.svg`: white version for dark backgrounds.
- `warehouse-flow.svg`: receiving, picking, packing and dispatch illustration.

The original mark uses one source and two equal paths, each ending at a dispatch
dock. It stays legible at favicon scale. Keep clear space of at least one stroke
width around it. Use the primary mark at 24px or larger; test at 16px for favicons.
Do not recolor orange to imply success: outcome colors belong to measured evidence.

SVG paths are editable and need no external fonts. The illustration's text uses
Arial with a sans-serif fallback. Assets are covered by the repository MIT license.
